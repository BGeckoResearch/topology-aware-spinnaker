Recommended reproducibility package structure

spinnaker_repro_package/
  README.txt
  code/
  outputs/
  paper/
  metadata/

Contents:
- code/: full benchmark scripts and routing prototypes
- outputs/: raw CSV/JSON outputs from the benchmark runs
- paper/: LaTeX manuscript and auxiliary paper-ready snippets
- metadata/: environment summary, version info, run commands, and notes

Intended use:
Archive this folder as a zip or place it in a public repository/release associated with the manuscript.
